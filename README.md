# Homebrew tap

Homebrew installation for [sidecar-comments](https://github.com/trogers1/sidecar-comments),
a CLI for sidecar comments on text files.

## Install

```sh
brew install trogers1/tap/sidecar
sidecar --output json version
```

Supported platforms: **macOS Apple Silicon** and **Linux x86-64**. The formula
installs prebuilt, SHA-256-checked binaries from stable GitHub releases; Go is
not required. Intel Macs and ARM Linux are not supported by this formula.

## Update

```sh
brew update
brew upgrade sidecar
```

## Maintenance

`Formula/sidecar.rb` is generated by the release workflow in
[`sidecar-comments`](https://github.com/trogers1/sidecar-comments).
After native verification and stable release publication, that workflow commits
the new version and verified archive checksums here. Rolling `latest` builds do
not update this tap. There is no separate release workflow in this repository.

Do not hand-edit the generated formula. See the
[release runbook](https://github.com/trogers1/sidecar-comments/blob/main/docs/releases.md#homebrew-tap)
for token setup and tap-only recovery. The token is stored in the source
repository's Actions secrets, never here.

To validate a published formula on a supported host:

```sh
brew tap trogers1/tap
brew install trogers1/tap/sidecar
brew test trogers1/tap/sidecar
brew audit --strict trogers1/tap/sidecar
```

Report CLI or packaging issues in
[sidecar-comments](https://github.com/trogers1/sidecar-comments/issues).
